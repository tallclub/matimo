Agents That Extend Themselves

Most SDKs give agents tools. Matimo gives agents the ability to build new tools — validated, approved, and live — without restarting. The meta-tool layer is Matimo's core differentiator.

import { MatimoInstance } from 'matimo';

const matimo = await MatimoInstance.init();
const result = await matimo.execute('slack_send_channel_message', {
    channel: '#general',
    text: 'Hello Matimo!'
});
const result = await matimo.execute('matimo_create_tool', {
    name: 'fetch-weather',
    yaml_content: `
name: fetch-weather
version: "1.0.0"
description: Get current weather for a city
execution:
    type: http
    method: GET
    url: https://wttr.in/{city}?format=j1
parameters:
    city:
        type: string
        description: City name to get weather for
        required: true
    `
});
await matimo.execute('matimo_approve_tool', {
    name: 'fetch-weather'
});
await matimo.execute('matimo_reload_tools');
const weather = await matimo.execute('fetch-weather', 
    { city: 'Bangalore' });
import asyncio
from matimo import Matimo

async def main():
    matimo = await Matimo.init()
    result = await matimo.execute('slack_send_channel_message', {
        'channel': '#general',
        'text': 'Hello Matimo!'
    })
    print(result)

asyncio.run(main())
result = await matimo.execute(
    'matimo_create_tool', {
    'name': 'fetch_weather',
    'yaml_content': """
name: fetch-weather
version: "1.0.0"
description: Get current weather for a city
execution:
    type: http
    method: GET
    url: https://wttr.in/{city}?format=j1
parameters:
    city:
        type: string
        required: true
    """
})
await matimo.execute('matimo_approve_tool', {
    'name': 'fetch_weather'
})
await matimo.execute('matimo_reload_tools')
weather = await matimo.execute(
    'fetch_weather', {'city': 'Bangalore'})

Four Integration Patterns

Choose what works best for your use case. Both TypeScript and Python SDKs support all patterns.

1

Factory Pattern

Simple and direct. Load tools and execute by name. Perfect for CLI tools and quick prototypes.

const matimo = await MatimoInstance.init();
await matimo.execute('tool-name', params);
matimo = await Matimo.init()
result = await matimo.execute('tool-name', params)
2

Decorator Pattern

Class-based approach. Use @tool decorator for natural, object-oriented tool execution.

@tool('tool-name')
async myMethod(param) {
  // Auto-executed
}
@tool('tool-name')
async def my_method(self, param):
    # Auto-executed
    pass
3

Framework Integration

Full LangChain, CrewAI integration. Convert tools to framework schemas automatically.

const tools = matimo
  .listTools()
  .map(t => toLangChainSchema(t));
from matimo import convert_tools_to_langchain
tools = convert_tools_to_langchain(
    matimo.list_tools(), matimo
)
4

MCP Server

Run Matimo as a standalone MCP server. Claude Desktop, Cursor, and any MCP client see all your tools instantly.

// stdio (Claude Desktop)
npx matimo mcp

// HTTP (remote agents)
npx matimo mcp --transport http
# stdio (Claude Desktop)
python -m matimo.mcp

# HTTP (remote agents)
python -m matimo.mcp --transport http
