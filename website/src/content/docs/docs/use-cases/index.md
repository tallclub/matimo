title: "Use cases"
description: "Three common jobs for Matimo OSS: require human approval for risky agent calls, serve governed tools to Claude Desktop or Cursor, and let an agent write tools safely."
---
Matimo sits between an agent and its tools. These pages each start from a job you want done and show the shortest path, with the limits stated.

| I want to | Page |
|-----------|------|
| Make an agent ask a person before it deletes data or runs a shell command | [Require approval for risky agent calls](/docs/use-cases/approve-risky-calls/) |
| Give Claude Desktop, Cursor or Windsurf a set of tools I control | [Serve governed tools to Claude Desktop and Cursor](/docs/use-cases/serve-tools-over-mcp/) |
| Let an agent write its own tool, but not run it until someone approves | [Let an agent write tools safely](/docs/use-cases/agent-writes-tools/) |

Not sure Matimo is the right fit? See [Why Matimo OSS](/docs/why-matimo/), which also lists what it does not do. Matimo governs tool calls. It does not replace your own authentication, and it holds no compliance certifications.
