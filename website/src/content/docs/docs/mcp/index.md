title: "Contributor Guides: Provider Packages with Copilot and MCP"
---
These guides cover one workflow: building a new provider package in this repository with VS Code Copilot's **Matimo Tool Creator** agent, which checks its work with tools from Matimo's own MCP server.

For running Matimo as an MCP server for your own agents, the `matimo mcp` CLI, Claude Desktop and Cursor configs, transports, auth, approval over MCP, see **[MCP.md](/docs/mcp-server/)**.

| Guide | Read it when |
|-------|--------------|
| [SETUP_GUIDE.md](/docs/mcp/setup-guide/) | You are setting the workflow up for the first time (about 15 minutes) |
| [QUICK_REFERENCE.md](/docs/mcp/quick-reference/) | You need a command, a tool input or a file path |
| [MAINTENANCE_GUIDE.md](https://github.com/tallclub/matimo/blob/main/docs/mcp/MAINTENANCE_GUIDE.md) | You change the SDK and need to keep the agent and skills accurate |
| [NAVIGATION_MAP.md](https://github.com/tallclub/matimo/blob/main/docs/mcp/NAVIGATION_MAP.md) | You are looking for the right document for a task |

Building a provider by hand instead? Follow [ADDING_TOOLS.md](/docs/tool-development/adding-tools/), the agent follows the same steps.
