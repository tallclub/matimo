## Extracted summary

- **Information Collection**: personal data (names, emails), derivative
  data (IP addresses, browser info), and API-related data from Google/YouTube
  integrations.
- **Data Usage**: account management, platform functionality, security,
  customer support, legal compliance.
- **Google Data Protection**: states Composio does not "use or transfer
  Google user data for serving ads," and prohibits using such data for
  AI/ML model development.
- **YouTube API Compliance**: YouTube data retention capped at 30 days,
  automatic deletion/refresh.
- **Security Measures**: encryption, access controls, audits, incident
  response.
- **User Rights**: access/correct/delete data, withdraw consent, request
  copies — via tech@composio.dev.
- **Cookies**: session, performance, analytics.
- **Policy Updates**: communicated via email, website updates, or platform
  notices.

This snapshot is a single-pass AI summary and was not cross-checked with a
second extraction the way the ToS was. Treat it as a pointer to what topics
the policy covers, not as citable clause text.
