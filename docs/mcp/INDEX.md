# Contributor Guides: Provider Packages with Copilot and MCP

These guides cover one workflow: building a new provider package in this repository with VS Code Copilot's **Matimo Tool Creator** agent, which checks its work with tools from Matimo's own MCP server.

For running Matimo as an MCP server for your own agents — the `matimo mcp` CLI, Claude Desktop and Cursor configs, transports, auth, approval over MCP — see **[MCP.md](../MCP.md)**.

| Guide | Read it when |
|-------|--------------|
| [SETUP_GUIDE.md](SETUP_GUIDE.md) | You are setting the workflow up for the first time (about 15 minutes) |
| [QUICK_REFERENCE.md](QUICK_REFERENCE.md) | You need a command, a tool input or a file path |
| [MAINTENANCE_GUIDE.md](MAINTENANCE_GUIDE.md) | You change the SDK and need to keep the agent and skills accurate |
| [NAVIGATION_MAP.md](NAVIGATION_MAP.md) | You are looking for the right document for a task |

Building a provider by hand instead? Follow [ADDING_TOOLS.md](../tool-development/ADDING_TOOLS.md) — the agent follows the same steps.
