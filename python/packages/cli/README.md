# matimo-cli

> Command-line interface for the [Matimo](https://matimo.dev) AI tools SDK.

```bash
pip install matimo-cli
```

## Commands

```
matimo install slack gmail   # Install provider packages
matimo list                  # List installed tools
matimo search email          # Search available tools
matimo mcp                   # Start MCP server (Claude Desktop / Cursor)
matimo doctor                # Diagnose your Matimo setup
matimo review                # Review agent-created tools
```

See [matimo.dev/docs](https://matimo.dev/docs) for full documentation.
